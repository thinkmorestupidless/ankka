# Tasks: WebAssembly Hosting

**Input**: Design documents from `/specs/016-wasm-hosting/`

**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md), [research.md](./research.md),
[data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md)

**Tests**: included. This repository's suites are the proof for every feature; the spec's success
criteria name what must be proven (the fixtures, the conformance suite in both shapes, the journal
in both directions, a trap losing nothing, sixty-four blocked calls costing one); the conformance
suite already exists, so most of this feature's tests are written before its code and the work is
making them pass.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel — different files, no dependency on an incomplete task
- **[Story]**: US1 (an entity in Rust, hosted in-process), US2 (tested without and with the host),
  US3 (every component kind, both shapes, proven compatible), US4 (deployed as one container),
  US5 (published, scaffolded and taught)

Paths are repository-relative. Abbreviations: `SC` = `sidecar/src/main/scala/com/thinkmorestupidless/ankka/sidecar`;
`SCT` = `sidecar/src/test/scala/com/thinkmorestupidless/ankka/sidecar`; `RS` = `sdks/rust`;
`LIB` = `sdks/rust/ankka/src`; `EX` = `sdks/rust/examples/shopping-cart`; `PY` = `sdks/python/src/ankka`
and `TS` = `sdks/typescript/src` (the working examples every crate-side task mirrors); `SK` =
`tools/docs/skill`; `SPIKE` = `sidecar/src/test/rust/spike-guest`. Where a task mirrors a Python or
TypeScript file it names it; read it first, then write the Rust that says the same thing in the
language's idiom (plan, "Structure Decision"). The ABI is [contracts/wasm-abi.md](./contracts/wasm-abi.md)
and nothing below departs from it without amending it first.

## Implementation strategy

**MVP is US1**: the host's machinery, the crate's codec and event sourced entity, the example's
cart and API, and the conformance suite's discovery and event sourced cases green against a module.
That is the point at which the ABI, the stateless shape and the codec are all proven on the real
