# Tasks: Telemetry Export — Traces and Metrics Leave the Instance over OTLP

**Input**: Design documents from `/specs/026-telemetry-export/`

**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md), [research.md](./research.md),
[data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md)

**Tests**: included, and first. This repository's rule is that each acceptance scenario ends as a
test that fails without the feature, and the plan's "verify first" list turns each fact read from
code or a dependency into a test before the code that relies on it. The scenarios are in
`features/observability/` and one outline of `features/secrets/platform-settings.feature`; where
a task says "case", it means a `test(...)` in the named suite, named for the scenario it holds.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel — different files, no dependency on an incomplete task
- **[Story]**: US1 (one request across two services is one trace in the collector), US2 (metrics
  arrive beside the traces, and logs name their trace), US3 (services opt into nothing; the
  installation points them at one collector), US4 (a collector that is down costs the service
  nothing), US5 (a local installation has somewhere to send, and somewhere to look)

Paths are repository-relative. Abbreviations, each followed by
`…/com/thinkmorestupidless/ankka/<module>` where it is a Scala tree: `CORE`/`CORET` =
`modules/core/src/{main,test}/scala/…/core`; `RT`/`RTT` =
`modules/runtime/src/{main,test}/scala/…/runtime`; `HTTP`/`HTTPT` =
`modules/http/src/{main,test}/scala/…/http`; `GRPC`/`GRPCT` =
`modules/grpc/src/{main,test}/scala/…/grpc`; `AGENT` = `modules/agent/src/main/scala/…/agent`;
`TKT` = `modules/testkit/src/test/scala/…/testkit`; `TEL`/`TELT` =
`modules/telemetry-otlp/src/{main,test}/scala/…/telemetry`; `SC`/`SCT` =
`sidecar/src/{main,test}/scala/…/sidecar`; `OP`/`OPT` = `operator/src/{main,test}/scala/…/operator`;
`API`/`APIT` = `controlplane-api/src/{main,test}/scala/…/controlplane/api`; `CPT` =
`controlplane/src/test/scala/…/controlplane`; `PXT` = `proxy-core/src/test/scala/…/proxy/core`;
`KUST` = `kustomization`; `DOCS` = `docs`; `SKILL` = `tools/docs/skill`. "R*n*" is a section of
`research.md`; "V*n*" an item of its *Verify first, gathered* list; a contract is named by its
file under `contracts/`.

The branch `026-telemetry-export` exists, in the worktree `.claude/worktrees/026-telemetry-export`.
Every `sbt` command below takes `-Dankka.cluster.tests=off` unless the task names a k3s suite.

## Phase 2: Foundational — the recorder holds what a collector needs

**Purpose**: R3 to R8. A trace id of two halves, span ids unique across instances, a clock
anchor, a kind, a mark for an unknown caller, a read cursor, and a tally since the instance
started. Every story stands on it.

**⚠️ CRITICAL**: after this phase every existing suite must pass untouched in what it asserts.
The local console's and the observe port's answers do not change: a trace is still keyed by the
low half in hex, and a span with an unknown caller still reads as a root.

### Tests first

- [ ] T007 [P] Extend `RTT/RecorderSuite.scala` per `contracts/scala-api.md` (*The recorder*): a span begun with a high half reads back with it; two recorders' first span ids differ and neither is 1; ten thousand span ids contain no `0` and no `Recorder.UnknownCaller`; a span begun with `SpanKind.Client` reads back as one, and `Internal` is the default; `epochNanos(span.startedNanos)` is within one second of the wall clock; a span begun with the parent `Recorder.UnknownCaller` reads back with `parentSpanId == 0` and `callerUnknown == true`; `snapshot()` returns the same spans in the same order as before for a ring written the old way.
- [ ] T008 [P] Write `RTT/RecorderCursorSuite.scala` per R6: every span is returned exactly once across repeated `read`/`commit`; a batch that is not committed is returned again; a ring of 8 written 20 times before the first read reports `lost == 12` and returns the newest 8; a span still in flight when first passed is returned by a later read once complete, and spans after it were not held back by it; an in-flight span whose slot is reused counts as lost; `read(max)` never returns more than `max` and resumes where it stopped; under four writer threads and one reader for 200 ms, the spans returned plus `lost` equal `recorder.recorded`, and no returned span has a component, handler and trace id from different writes (each writer uses refs and ids that identify it).

## Implementation Strategy

**MVP**: Phases 1, 2 and 3 — User Story 1. A service with the module on its classpath and an
address in its environment exports its spans, and a request that crosses services is one trace.
It needs no operator, no manifests and no cluster to be useful: a developer can point two local
services at a collector with one variable.

**Then, each a mergeable step**:

1. Phase 2 alone is mergeable: it changes no behaviour a user can see, and it repairs span ids
   that already cross nodes.
2. US1's context half (T017–T031): traces join across services in every instance's own console
   view, exporter or not.
3. US1's export half, then US2's metrics and US4 — the module, complete.
4. US2's logs, at any point after Phase 2.
5. US3 (the operator) and US5 (the manifests and the telemetry store), then Phase 8 — the step that, once an installer
   sets the address, rolls every service once.
6. Documentation and the whole build.

## Notes

- A task that says "show it failing" is not done until it has been seen red and the break is confirmed gone (`git diff`, or a grep for what was changed).
- Read what a run says it ran. A munit filter needs its leading `*`; a benchmark without `-Dankka.benchmarks=on` reports its cases ignored; `RemoteOverlaySuite` skips without `kubectl`; a k3s suite that takes hours has been run on a sleeping laptop.
- Never log, print, describe or render a header's value. The suites assert it for the action, the rendered objects and the outage line; nothing asserts it for every log line, so it is the reviewer's to read for.
- Nothing interned may be unbounded: a call's span is named by an admitted service and a method, never a path, an address or an id.
- A parent is never guessed. Where a context cannot follow the work, the span says its caller is unknown.
