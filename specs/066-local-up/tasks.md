# Tasks: A project started on one machine with one command

**Input**: Design documents from `specs/066-local-up/`

**Prerequisites**: plan.md, spec.md, research.md (R1 to R17), data-model.md, contracts/cli.md,
contracts/project-files.md, contracts/local-project.md, quickstart.md

**Tests**: required. Every acceptance scenario ends as a test named after it that fails without
the feature (research R16 says which suite holds which). Within a task, write the test first and
see it fail.

**Paths**: `CLI` is `cli/src/main/scala/com/thinkmorestupidless/ankka/cli`, `CLITEST` is
`cli/src/test/scala/com/thinkmorestupidless/ankka/cli`, `CORE` is
`modules/core/src/main/scala/com/thinkmorestupidless/ankka/core`, `CORETEST` its `src/test` twin.

**Messages**: every refusal's words are the contract's (`contracts/cli.md`,
`contracts/project-files.md`); a test asserts them as written there.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: the user story the task serves (US1 to US7)

## Implementation strategy

MVP is Phases 1 to 3: a project of embedded services up and down with one command, proved against
Docker. Then the other two P1 stories (topics, environment), each adding to the same plan and the
same two suites; then companions and source-run services; then seeing; then the other hostings;
then the template, which is where the real services prove what the stand-in cannot; then the
pages and the measurements. Commit each task; a task whose check cannot be made to pass stops the
build there.

## Languages

No SDK surface is added (plan, "Languages reached"), so no per-language sample task exists: the
one new page documents commands that do not differ by language, and T045 writes each language's
default run command into it. Every hosting is reached by Phase 9.
